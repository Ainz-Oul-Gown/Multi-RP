# Модуль: Система NPC

> Ссылка на полный код: [context_supabase_functions.md](../context_supabase_functions.md)  
> Директория: `supabase/functions/_shared/`

## Обзор

NPC — полноценные сущности с памятью, отношениями, автономным поведением и боёвкой.

## Компоненты

### 1. Память NPC (npc-memory-engine + npc_relationship_engine.ts)

**Каскадная система памяти "5-5-5":**

```
vivid (яркие, ≤5)  →  medium (средние, ≤5)  →  belief (убеждения, ≤5)
     │                      │                        │
Новое событие          Если vivid>5:            Если medium>5:
сохраняется           самая старая перейдёт     6 средних сожмутся
как vivid             в medium                  в 1 belief через ИИ
                                                Если belief>5:
                                                самое старое удаляется
```

**Типы воспоминаний:**

| Тип | Описание |
|-----|---------|
| `impression` | Поверхностное впечатление (vividness 1-3) |
| `regular` | Обычное воспоминание (vividness 4-6) |
| `vivid` | Яркое воспоминание (vividness 7-10) |
| `belief` | Сжатое убеждение из 6+ средних воспоминаний |

### 2. Отношения (npc_relationship_engine.ts)

**Шкала отношений: -100 .. +100**

| Диапазон | Тир | Метка |
|---------|-----|-------|
| -100..-70 | `sworn_enemy` | Заклятый враг |
| -69..-35 | `hostile` | Враждебен |
| -34..-10 | `unfriendly` | Недружелюбен |
| -9..+15 | `neutral` | Нейтрален |
| +16..+50 | `friendly` | Дружелюбен |
| +51..+80 | `trusted` | Доверяет |
| +81..+100 | `devoted` | Предан |

После каждого взаимодействия:
1. ИИ оценивает яркость события (1-10) и `relationship_delta` (-30..+30)
2. Шкала обновляется: `new_score = clamp(old_score + delta, -100, 100)`
3. Воспоминание сохраняется в БД с эмбеддингом (pgvector)

### 3. Боёвка NPC (npc_combat_ai.ts)

NPC имеют:
- `combat_stats`: AC, HP, атаки
- `tier` (1-4): определяет силу
- `special_attacks[]`: уникальные способности по тиру
- `hit_dice`: D&D система хит-дайсов

### 4. Автономное поведение (npc_autonomous_engine.ts)

Главные NPC (`role = "major"`) действуют автономно между ходами через `simulate-npc-background`.

Типы автономных действий:
- `travel` — перемещение в другую локацию
- `hunt_combat` — охота/бой
- `trade_craft` — торговля/ремесло
- `train` — тренировка (XP)
- `quest` — выполнение квеста
- `rest` — отдых

### 5. Определение расы (npcRaceResolver.ts)

Интеллектуальное определение расы NPC по имени/категории/тегам:
```typescript
resolveNpcRace(npc, categoryParam, raceParam): string
```

## Таблицы БД (связанные с NPC)

|---------|---------|
| `npcs` | Основная таблица NPC мира |

## Жизненный цикл NPC за ход

```
1. Игрок взаимодействует с NPC (talk/attack/...)
2. Step 2 Engine обрабатывает действие
3. Step 3 Persistence обновляет состояние NPC (HP, location)
4. npc_memory_updater.ts оценивает взаимодействие через ИИ
5. Сохраняет воспоминание + обновляет шкалу отношений
6. После круга: npc_world_simulator симулирует жизнь мира
```
