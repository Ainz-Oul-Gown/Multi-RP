## Иерархия географии

```
World (мир)
  └── State (государство)  ← state_border_polygons (SVG/GeoJSON полигоны)
        └── Location (локация)
              └── Zone (зона внутри локации)  ← location_map (матрица расстояний)
```

## Таблицы

```sql
states (
  id, world_id, name, description,
  ruler_id (→ npcs.id),    -- правитель
  color TEXT,               -- цвет на карте
  polygon JSONB             -- границы государства
)

locations (
  id, state_id (или NULL для дикой зоны),
  name, type,               -- 'city' | 'village' | 'dungeon' | 'wilderness' | ...
  description,
  terrain_type,             -- 'open' | 'forest' | 'cave' | 'urban' | 'building' | 'mountain'
  location_map JSONB,       -- матрица расстояний между зонами
  coordinates JSONB         -- {x, y} на карте мира
)

routes (
  from_location_id, to_location_id,
  distance INT,             -- в условных единицах
  travel_time_hours INT
)

session_locations (
  session_id, location_id,
  terrain_type,
  location_map JSONB        -- может отличаться от базовой (ИИ генерирует при входе)
)
```

## location_map — Матрица расстояний

Каждая локация делится на **зоны** (rooms/areas).  
`location_map` — словарь `{zone_name: {zone_name: distance_tier}}`.

```json
{
  "Таверна": {
    "Зал": 1,
    "Кухня": 1,
    "Улица": 2
  },
  "Зал": {
    "Кухня": 1,
    "Улица": 2
  }
}
```

Тиры расстояний:
| Тир | Расстояние | Описание |
|-----|-----------|---------|
| 0 | ~0м | Та же комната/зона |
| 1 | ~10м | Рядом, сквозь стену |
| 2 | ~50м | Соседняя зона |
| 3 | ~200м | Другой квартал |
| 4 | ~1км | Другой конец города |
| 5 | >1км | Другой город |

## Генерация location_map (fog_location_generator.ts)

При входе в локацию ИИ генерирует `location_map` и `terrain_type`.  
Если ИИ недоступен — используется эвристический фоллбэк `buildFallbackLocationMap()`.

```typescript
ensureLocationMapAndTerrain({
  supabase, sessionId, locationId, locationName,
  locationType, locationDescription, isWildZone,
  openrouterApiKey, model
}) → LocationMapResult
```

## Дикие зоны (Wild Zones)

Локации без привязки к государству (`state_id IS NULL`).  
Генерируются процедурно при перемещении игрока в неисследованную территорию.

## Навигация по подзонам и GPS (Subzones & GPS)

- Локация может иметь подзоны (например: `Таверна -> Зал`, `Кухня`, `Подвал`).
- В `step1_router` ИИ определяет не только глобальное перемещение между локациями (`target_location`), но и перемещение внутри локации по подзонам (`moved_to_subzone`).
- Реализован двухконтурный матчинг зон/подзон:
  1. **ИИ GPS промпт**: список всех известных зон и подзон локации подаётся на вход модели.
  2. **Интеллектуальный Regex фоллбек**: если ИИ не вернул валидный JSON или вернул частичное название, эвристика сопоставляет фразы ("пойду в зал", "загляну на кухню") с подзонами текущей `location_map`.

## Уровни опасности местности (Danger Levels)

Все локации, подзоны и дикие зоны имеют параметр `danger_level`:
- `'safe'` (Безопасная зона): Базовый шанс случайных энкаунтеров ~2%. Окрестности мирных городов, столиц, охраняемые тракты.
- `'normal'` (Обычная зона): Базовый шанс энкаунтеров ~12%. Обычные леса, поля, равнины, провинциальные дороги.
- `'danger'` (Опасная зона): Базовый шанс энкаунтеров ~35%. Глубокие чащи, болота, заброшенные руины, логова разбойников.
- `'lethal'` (Смертельная зона): Базовый шанс энкаунтеров ~65%. Древние подземелья, земли нежити, драконьи пустоши.

### Дикие зоны (Wilderness / Wild Zones)
При выходе из поселения или ключевой локации в окрестные дикие зоны:
1. `sessions.current_wild_zone_danger_level` запоминает уровень опасности дикой зоны (наследуется от `locations.danger_level` или подзоны, либо рассчитывается GPS).
2. При перемещении внутри дикой зоны энкаунтеры рассчитываются на основе `current_wild_zone_danger_level`.
3. При возвращении в безопасный город или другую ключевую локацию `current_wild_zone_danger_level` сбрасывается в `NULL`.

## Перемещения и Матрица Плаузибильности (GPS)

### Градация дистанций и времени:
- **Малые дистанции (100–500 м)**: 5–15 минут. Прогулка по кварталу, выход на опушку, осмотр поляны, переход к соседнему строению.
- **Средние дистанции (0.5–5 км)**: 15–60 минут. Поход к заброшенной мельнице, пещере у подножия холма, переправе через реку.
- **Дальние дистанции (5–50+ км)**: несколько часов или дней. Путешествие между городами, фортами и ключевыми узлами карты мира.

### Плаузибильность генерации подлокаций:
AI GPS (`buildGpsPrompt`) оценивает географическую и логическую плаузибильность перемещения:
- **Плаузибильно (`is_plausible: true`)**:
  - Из леса → поляна, ручей, овраг, пещера, старая охотничья хижина.
  - Из города → торговая площадь, трущобы, порт, пригородные фермы, ворота наружу.
  - Из таверны → улица перед таверной, переулок, соседний квартал.
- **Неплаузибильно (`is_plausible: false`)**:
  - Из дикого леса → королевская сокровищница, банк, дворец (не могут существовать в дикой глуши в 10 км от цивилизации).
  - Из закрытого охраняемого подземелья → мгновенный выход в другой город без ключа/портала.

При `is_plausible: false`:
- Движок помечает действие как отклонённое (`movement_rejected = true`).
- `MoveHandler` возвращает `success: false` с объяснением причины (`rejection_reason`).
- Факты фиксируют: `Персонаж не смог: <причина>`.
- Нарратор художественно описывает безуспешность поиска (например: блуждание по чаще без намёка на сокровищницу). Новая подлокация в БД **не создаётся**.

## Охота и Намеренный Поиск (Targeted Encounters)
Если игрок декларирует целенаправленный поиск существа или ресурса ("выслеживаю кабана", "ищу волка по следам"):
1. Роутер классифицирует намерение как `encounter_intent: { type: "targeted", target_name: "Кабан" }`.
2. В `step2_engine.ts` применяется повышенный множитель вероятности встречи (`intentMult = 3.0`), а также бонус от модификатора Мудрости (`WIS`).
3. При успехе спавнится именно искомое существо (поиск по `npcs` мира, `creature_templates` или создается энкаунтер с точным именем).
4. При неудаче нарратор сообщает о безуспешном выслеживании, не спавня случайных нерелевантных монстров.
